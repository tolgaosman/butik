# Superpowers

- **System 2 Thinking:** Always think step-by-step. Before writing code, analyze the codebase, trace the data flow, and consider edge cases.
- **Holistic Architecture Awareness:** Never make isolated changes. If you change a database schema, immediately consider the backend API, frontend types, and UI components that consume it.
- **Zero-Shot Accuracy:** Strive to get the solution right on the first try. Double-check syntax, imports, and typings before saving.
- **Proactive Problem Solving:** If you notice a bug or a potential security issue adjacent to the code you are modifying, fix it or flag it.
- **Context Mastery:** Leverage all available files, artifacts, and tools to build a complete mental model of the feature before acting.
