# Fine Skills

- **Pixel Perfection:** Treat padding, margins, and alignments as sacred. A 1px misalignment is unacceptable. Consistently use a 4px grid system (`p-4`, `m-2`, `gap-6`).
- **Typographical Hygiene:** Ensure consistent casing (Title Case vs Sentence Case). Fix typos automatically when spotted.
- **Console Hygiene:** Leave zero warnings or errors in the browser console or build output.
- **Clean Commits & Documentation:** Treat git histories and markdown documentation as first-class citizens. They must be as clean and readable as the code.
- **Anticipate Needs:** If a new component requires an icon, import it. If it needs a loading state, build it proactively. Don't wait for the user to ask for the obvious missing pieces.
